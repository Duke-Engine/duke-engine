# The line-drawn skill icons

The four icons the skill bar used before the painted set arrived, kept because
they are the only skill art in the game that somebody with a licence to honour
drew by hand — see `License.txt` beside them, which is game-icons.net's and asks
for attribution.

Nothing reads this folder. They are here rather than deleted because the
painted set is one generator's output and a generator is not a supplier: if it
has to be redone, starting from art that is known to work beats starting from
nothing.

`CREDITS.md` no longer lists them, because nothing in the game shows them.
